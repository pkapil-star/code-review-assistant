Development Journal — Preetpal

1. Vercel Could Not Parse requirements.txt

The deployment failed because requirements.txt had been saved in UTF-16LE encoding, causing parsing errors. The file was rewritten using UTF-8 encoding.

2. GitHub Rejected the Push Because of a Detected Secret

GitHub blocked the push after its secret scanner flagged a Stripe-like key in demo data. The value was confirmed to be fabricated test content and handled through GitHub's allow-secret process.

3. GitHub App Private Key Was Missing in Production

The GitHub App private key was stored in a gitignored file, so it was unavailable in the Vercel deployment. Support was added for loading the PEM key from the GITHUB_PRIVATE_KEY environment variable.

4. GitHub Webhook Returned HTTP 401

The first webhook delivery failed because the GitHub App webhook secret had been cleared and no longer matched the server's configured secret. A new secret was configured on both GitHub and Vercel, followed by a redeployment.

5. GitHub App Authentication Failed

The application faced authentication issues while communicating with the GitHub API. The App ID, private key configuration, and JWT generation logic were checked and corrected.

6. Webhook Payload Parsing Error

The application encountered issues while extracting information from incoming GitHub webhook payloads. The payload structure and field mappings were reviewed to ensure correct data extraction.

7. Pull Request Review Comments Were Not Posted Correctly

The automated review results were generated, but comments were not appearing correctly on GitHub pull requests. The GitHub API request format and repository permissions were checked and updated.
