Development Journal — Pranshu Kapil (Team Leader)

1. Local Server Could Not Start on Port 8000

Uvicorn could not bind to port 8000 because Windows blocked access to that port. The application was started successfully on port 8001 instead.

2. Vercel Rejected the Project Name

Vercel rejected the project name because it contained uppercase characters. The deployment was retried with an explicitly provided lowercase project name.

3. Dashboard Deployment Showed Only a JSON Response

The deployed site displayed a basic JSON status response instead of the dashboard because the React frontend was on a separate branch and had not been merged into the main branch. The frontend branch was merged into the main branch.

4. Deployed Dashboard Did Not Show the Latest Frontend Build

The deployment continued serving the old build because the frontend build files were not included in the Vercel function bundle. The frontend was rebuilt and the Vercel configuration was updated to include the build output.

5. Git Merge Conflicts During Branch Integration

Conflicts occurred while merging the frontend development branch into the main branch. Files such as .gitignore and requirements.txt required manual conflict resolution before the merge could be completed.

6. API Endpoints Returned Incorrect Responses

Some API endpoints did not return the expected response format, causing issues when connecting the frontend dashboard with the backend. The response handling and API integration logic were reviewed and corrected.

7. Environment Variables Were Not Loaded Correctly

The application failed to access some configuration values during deployment because environment variables were missing or incorrectly configured. The deployment environment settings were updated.

8. Frontend and Backend Integration Issues

The React frontend initially faced problems communicating with the FastAPI backend. API URLs and request handling were checked and updated to establish proper communication.

9. Dashboard Data Was Not Updating Properly

The dashboard did not immediately reflect newly generated code review results. The data-fetching and state-update logic was reviewed to ensure that updated review information appeared correctly.

10. Production Deployment Configuration Issues

The application worked locally but encountered configuration differences after deployment. The Vercel configuration and production environment settings were reviewed to make the deployed application work correctly.
