Development Journal — Sehajpal

1. Pull Request Webhook Events Were Not Being Delivered

GitHub was not sending pull_request events because the event subscription was disabled and the app installation did not include the target repository. The event was enabled and repository access was updated.

2. Review Jobs Remained Stuck in the Running State

The review job remained marked as running because Vercel terminated the in-process background worker after the webhook response was sent. The review pipeline was changed to run inline and be awaited by the webhook handler.

3. Review Pipeline Failed with HTTP 502

The review failed because the PullRequestRecord required an author field that was missing from the parsed PullRequestEvent. The PR author and avatar were added to the event model and passed through to the dashboard records.

4. Dashboard Became Blank After the Monochrome Theme Change

After a theme change, the deployed dashboard displayed a blank page even though the server-side files and API returned successfully. The theme change was reverted, and the dashboard was later confirmed to render correctly.

5. Static Analysis Results Were Not Displayed Correctly

Some code analysis findings were not appearing in the expected format. The result-processing logic was reviewed to ensure that detected issues were correctly structured before being displayed.

6. Pull Request Review Score Was Not Calculated Correctly

The review score did not always reflect the detected code issues. The scoring logic was reviewed and adjusted to improve consistency between findings and the final review score.

7. Dashboard Review Status Was Not Updated Properly

The dashboard did not consistently display the correct status after a review was completed. The review status update logic was checked to ensure that completed jobs were reflected correctly.
