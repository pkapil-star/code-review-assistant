Development Journal — Pranshu Kapil (Team Leader)

1. Local Server Could Not Start on Port 8000

Uvicorn could not bind to port 8000 because Windows blocked access to that port. The application was started successfully on port 8001 instead.

2. Vercel Rejected the Project Name

Vercel rejected the project name because it contained uppercase characters. The deployment was retried with an explicitly provided lowercase project name.

3. Dashboard Deployment Showed Only a JSON Response

The deployed site displayed a basic JSON status response instead of the dashboard because the React frontend was on a separate branch and had not been merged into the main branch. The frontend branch was merged into the main branch.

4. Deployed Dashboard Did Not Show the Latest Frontend Build

The deployment continued serving the old build because the frontend build files were not included in the Vercel function bundle. The frontend was rebuilt and the Vercel configuration was updated to include the build output.
